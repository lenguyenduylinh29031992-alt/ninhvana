# Chuẩn hóa giao diện

## Thay đổi chính

- Nền và card ấm hơn, bo góc 16px, viền nhẹ, bóng đổ sâu vừa phải.
- Sidebar 252px, khoảng cách mục lớn hơn, active dạng gradient + vạch brand.
- Topbar 68px, nền mờ nhẹ, căn lề đồng bộ với nội dung.
- PageHeader:
  - Eyebrow có vạch brand.
  - Tiêu đề lớn hơn, khoảng cách rõ hơn.
  - Nút hành động xuống dòng gọn ở màn hình dưới 1536px.
- Bảng:
  - Header nền muted, sticky-style, chữ 10px.
  - Ô dữ liệu 13px, padding thoáng hơn.
  - Hover theo tông brand-soft.
- Button bo 10px, chiều cao nhỏ nhất 36px.
- Nội dung chính rộng tối đa 1560px, padding desktop 40px.
